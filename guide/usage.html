用户指南 ​

面向普通用户的 CircleChat 功能手册。

注册与登录 ​

  • 访问根路径 / 自动跳转登录页。
  • 可注册（开放注册时）；注册后可能需等待管理员审核（pending 状态无法登录，通过后才能登录）。
  • 登录失败连续 5 次会被限速 10 分钟。

界面组成 ​

  • 左侧栏：会话列表（群组 / 私聊）、好友、群的入口、顶部铃铛（站内信箱）。
  • 主区：当前会话的消息流与输入框。
  • 支持 zh / en / ja 三种界面语言（右上角切换）。

私聊 ​

  • 通过搜索/加好友建立私聊；必须先互为好友才能发起私聊。
  • 在线状态、正在输入提示（仅好友可见）。

群组 ​

  • 可创建群、搜索并加入群、申请入群（需审核的群）。
  • 群主 / 管理员可：解散、重命名、设公告、移出成员、审核入群、转让群主、删除群文件。
  • 群内多人实时聊天。

发消息 ​

  • 文本消息支持 Markdown 渲染与代码高亮（highlight.js），支持数学公式（MathJax）。
  • 可以引用回复某条消息。
  • 支持发送：图片 / 音频 / 视频 / 文件，以及合并转发。

上传文件 ​

  • 单文件上限 100MB；大文件走分片断点续传（自动，无需手动操作）。
  • 上传时界面会显示分段进度条与总百分比，文件面板出现时消息上移。
  • 上传类型有白名单 + 图片魔数校验，非白名单会被拒绝。

表情回应 ​

对任意一条未撤回的消息，可添加 / 切换 / 取消 emoji 回应。

撤回消息 ​

  • 可撤回自己的消息。
  • 管理员可撤回任意人的消息（前端会标记为管理员代删）。

消息操作 ​

消息上可打开上下文菜单（右键 / 长按），支持：

  • 引用回复
  • 表情回应
  • 撤回（若允许）
  • 举报（弹出输入框填写原因，进入管理员处理）
  • 转发 / 合并转发
  • 音频拖动进度、音视频下载

站点信箱 ​

点击顶部铃铛打开信箱，含三个标签：

  • 公告：系统级全局公告。
  • 通知：个人通知（如处罚结果）。
  • 我的处罚：我的历史处罚记录。

个人中心与账号安全 ​

在个人中心可：

  • 修改昵称、签名、头像。
  • 修改密码（需要旧密码）。
  • 设置在线 / 隐身 / 离开状态。
  • 开启 / 关闭两步验证（TOTP 二维码）。

安全提示 ​

  • 密码 SHA256 加盐存储，会话用 HttpOnly Cookie。
  • 生产环境请尽快修改管理员默认密码（若你是管理员）。
  • 被禁言 / 封禁后无法继续发消息，前端会收到处罚提示。
