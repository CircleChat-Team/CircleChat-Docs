本页目录

管理后台 ​

面向管理员的治理手册。管理相关能力主要在管理面板中，接口实现见管理端 API。

入口与权限 ​

仅管理员账号可用管理面板。所有管理操作均受 admin 角色限制，会写入审计日志。

用户管理 ​

  • 用户列表：查看全部用户及状态（激活 / 待审 / 封禁）。
  • 新增用户：npm run adduser -- <用户名> [密码] 或管理面板一键新增。
  • 删除用户：移除用户。
  • 重命名：修改用户名。
  • 改头像：设置用户头像。
  • 重置密码：为用户设置新密码。

注册审核 ​

开放注册产生的账号可能进入 pending（待审核）状态：

  • 通过：账号激活，用户可登录。
  • 拒绝：账号被拒，无法登录。
  • 未通过审核的账号登录时返回 403 对应提示。

举报与处罚 ​

  • 举报处理：查看用户上报的举报（/api/admin/reports），可驳回或执行处罚。
  • 处罚类型：禁言（mute）、封禁（ban）、IP 封禁（ipBan）。
  • 奖惩记录：查看全部处罚（/api/admin/penalties），可撤销已有处罚。
  • 自动通知：执行处罚后，系统自动向被处罚用户写入一条站内「通知」，并在其实时连接上推送 penalty 消息（前端禁用输入）。

公告发布 ​

发布系统级公告（全员可见，出现在每用户信箱「公告」标签）。可删除已有公告。

文件管理 ​

  • 查看已上传文件列表（与 FILE_TTL_DAYS 保留策略配合）。
  • 可手动删除指定文件。

操作日志 ​

  • 分页查看审计 / 操作日志（登录、登出、发消息、上传、处罚、举报等活动）与来源 IP。
  • 全局所有 HTTP 请求与 WebSocket 连接额外写入 data/access.log（可配合外部监控）。

依赖命令行 ​

命令作用
npm run adduser -- <用户名> [新密码]新增/重置用户密码（服务端命令行）

更多安全与数据说明见配置说明 · 内置安全限制。
